Questions We Get Asked

How often should we test?

Annually at minimum, plus after any significant change such as a new application release, a cloud migration or a merger. Many clients move to a six-monthly cycle once a customer or insurer asks for it.

Is this the same as a vulnerability scan?

No. A scan automates known-signature checks and produces a long list with many false positives. A penetration test is a consultant actively trying to chain weaknesses together and demonstrate real impact, with the noise removed. We offer managed scanning as a supplement, not as a substitute.

Will testing disrupt our systems?

We agree a window, avoid anything destructive, and stop and call you if something unexpected happens. Production testing is routine, but we can test a staging environment where that makes sense.

Can you test our supplier's product?

Only with the supplier's written authorisation. We can help you request it and define scope, which is common for SaaS due diligence.
